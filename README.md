# PokéDex Scanner (wersja webowa)

Aplikacja: **https://mawodesign.github.io/pokedex-app/**

Na iPhonie otwórz adres w Safari → Udostępnij → **Do ekranu początkowego**.

To repozytorium zawiera tylko zbudowaną aplikację (`site/`) i codzienną kopię cen kart
(`mirror-tcgcsv.mjs`, dane z [TCGCSV](https://tcgcsv.com)). Kod źródłowy jest prywatny.
